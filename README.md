# ShopLink Ghana V2
Multi-business WhatsApp commerce MVP for Ghana.

Run:
npm install
npm start

Open http://127.0.0.1:3000
Seller setup: http://127.0.0.1:3000/seller

This is an MVP. It stores business/product data in data.json. Production upgrades should include authentication, Supabase/PostgreSQL, secure seller access, image uploads, payments, subscriptions, backups and HTTPS.
